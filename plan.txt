내가 모르는 단어의 뜻을 영어로 알려주는 프로그램. 모바일 앱 출시 가능성 열어둠. 집에서든 밖에서든 이어서 학습할 수 있도록.
	메인화면에서 배울 언어를 선택. 그 후 텍스트를 입력받으면 화면에 텍스트를 출력.
	각 단어를 클릭하면 아는 단어, 잘 모르는 단어, 모르는 단어 상태 선택 버튼(○, ◐, ●)과 사전 버튼 아이콘을 모은 작은 박스가 단어 위에 뜸. 단어상태를 아이콘을 눌러서 변경 가능. 사전 버튼을 누르면 사전 창이 뜸.
	단어의 상태를 아는 단어, 잘 모르는 단어, 모르는 단어 3가지로 구분. 단어에 색깔을 칠해줌. 아는 단어는 기본 색으로(검은색)
	사전은 언어별로 나눠서 저장함. 프로그램 시작 시 배울 언어를 선택하게 함. 사전이 지원하는 언어를 목록에 다 출력하면 복잡하므로 내가 배우고 싶은 언어만 목록에 출력되게 하고 싶음.
	단어의 뜻만 아는 것보다 문맥 안에서 뜻을 파악하는게 더 중요하므로, 문장도 마우스로 선택할 수 있게 함. 그러므로 단어 호버 박스보다 문장 호버 박스가 조금 더 커야 함. 문장을 클릭하면 문장 번역이 문장 근처에 뜸.
	텍스트가 길면 페이지를 구분함.
	화면 맨 아래의 상태 바에는 문서의 단어 개수, 단어 상태별 단어 개수 등의 통계를 출력.
	단어장 기능. 메인화면에서도 문서 내에서도 단어장에 접근 가능. 단어장 메인화면에서는 내가 배우고 있는 언어를 선택. 언어를 선택한 뒤의 화면에서는 단어의 상태(알음, 잘 모름, 모름)별로 구분해서 단어 목록을 출력.
